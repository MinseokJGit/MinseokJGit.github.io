<div class="heading">Research</div>
<div class="subheading">Programming languages for software engineering &amp; machine learning</div>

<p>I am broadly interested in developing programming language techniques for addressing challenges in various fields, including software engineering and machine learning. Specifically, I take pleasure in designing domain-specific programming languages (DSLs) and developing program synthesis algorithms to address these challenges.</p>

<ul class="topics">
  <li><strong>Pointer &amp; static analysis</strong> &mdash; designing DSLs and synthesis algorithms for effective, precise, and scalable pointer analysis, a key component in compiler optimization.</li>
  <li><strong>Explainable graph machine learning</strong> &mdash; programming language approaches to make graph-based machine learning models interpretable.</li>
  <li><strong>System software testing</strong> &mdash; DSLs tailored to identifying effective test cases in system software testing.</li>
  <li><strong>Program synthesis</strong> &mdash; algorithms for synthesizing programs and heuristics from data, applied throughout the above areas.</li>
</ul>
