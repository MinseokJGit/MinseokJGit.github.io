# minseokjgit.github.io

Personal/lab homepage of Minseok Jeon (Assistant Professor, DGIST), built with [Jekyll](https://jekyllrb.com/) and based on the [blueface](https://github.com/thien/blueface) theme.

Published via GitHub Pages at <https://minseokjgit.github.io/>.

## Local development

```sh
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.

## Structure

- `index.md` — About / home page
- `members/` — Lab members
- `research/` — Research interests and talks
- `publications/` — Publication list
- `courses/` — Teaching
- `_layouts/`, `_includes/`, `css/` — theme templates and styles
